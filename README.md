# selectssm

A self-contained selective state space model (Mamba) sequence layer, implemented **twice** —
once in JAX/Flax and once in Rust ([burn](https://burn.dev)) — sharing one common vocabulary
and one set of golden test vectors so the two implementations are verified to agree numerically.

The layer provides:

- **`SelectiveSSM`** — a causal selective SSM (Mamba), with an anti-causal `reverse=True` mode.
- **`BidirectionalMamba`** — a non-causal forward+reverse block with gated output projection.
- **RCPS** reverse-complement parameter-sharing wrappers for exact RC equivariance.
- An optional **complex-SSM "RoPE trick"** (`use_complex_ssm`) — the Mamba-3 data-dependent
  rotary mechanism (arXiv:2603.15569, Prop. 2/3) that unlocks state-tracking tasks such as
  parity. It is **not** standard fixed-frequency positional RoPE; the rotation angles are
  produced data-dependently from the input.

```
selectssm/
├── jax/         # JAX/Flax implementation (pip-installable package `selectssm`)
├── rust/        # Rust/burn implementation (ndarray + wgpu backends)
└── fixtures/    # shared golden vectors generated by jax/, the numeric source of truth
```

## Shared vocabulary

Both implementations use the same names for modules, configuration fields, and the documented
math, so the two ports read in parallel:

| Concept | JAX | Rust |
|---|---|---|
| Causal selective SSM | `SelectiveSSM` | `SelectiveSsm` / `SelectiveSsmConfig` |
| Bidirectional block | `BidirectionalMamba` | `BidirectionalMamba` / `BidirectionalMambaConfig` |
| RC parameter sharing | `RCPSWrapper` | `RcpsWrapper` (feature `rcps`) |
| Chunked scan | `ssm_chunked_scan` | `ssm_chunked_scan` |
| Complex RoPE trick | `use_complex_ssm`, `theta`, cumulative angle `Phi` | identical field/term names |

Config field names and semantics match exactly: `hidden_features`, `chunk_size`,
`n_channel_groups`, `reverse`, `complement`, `use_complex_ssm`, `dt_rank`, `dt_proj`,
`dt_min`, `dt_max`, `shift_conv_size`, `activation`, `expansion_factor`, …

## The complex-SSM RoPE trick (shared math)

A complex diagonal SSM is realised by a real recurrence: a signed, data-dependent angle
`theta` (one per `(real, imag)` state pair) is projected from the input; the cumulative angle
`Phi_t = sum_{s<=t} theta_s` is formed as a prefix sum **carried across chunks**; and the `B`
and `C` projections are rotated by `R(-Phi)` before the (unchanged) real recurrence. The decay
magnitude is tied across each state pair so each 2×2 block is a scaled rotation, making the
factorization exact. Feature-off is bitwise-identical to the plain real SSM.

## Build & test each implementation

### JAX (`jax/`)

```bash
pip install -e './jax[test]'
cd jax && pytest              # add -m "not slow" to skip the parity training test
```

See [`jax/README.md`](jax/README.md). Installable standalone:
`pip install "git+ssh://git@github.com/ihh/selectssm.git#subdirectory=jax"`.

### Rust (`rust/`)

```bash
cd rust
cargo test                                   # ndarray backend (deterministic)
cargo test --features wgpu                   # add the wgpu (WebGPU) backend
cargo test --features rcps                   # include the RCPS wrapper + its fixtures
```

See [`rust/README.md`](rust/README.md).

## Cross-language numeric parity

JAX is the reference oracle. `jax/scripts/generate_fixtures.py` serializes, from seeded inputs
and seeded parameters, the inputs, parameters, forward outputs, and gradients (VJP of a fixed
scalar loss) for `{causal, reverse, bidirectional, rcps} × {complex off, on}`, including one
sequence length that is not a multiple of the chunk size. The Rust suite loads these
`fixtures/*.safetensors` and asserts forward parity (~1e-4 relative) and gradient parity
(~1e-3 relative) on both the ndarray and wgpu backends.
